Configuração dos canais ThingSpeak

Os IDs são salvos apenas no navegador. As Read API Keys ficam somente na memória desta aba e não são gravadas no armazenamento local. Para canais privados, não publique as chaves no código-fonte nem em um site público: use um proxy seguro com backend. Os campos de origem devem ser Field 1 = temperatura e Field 2 = umidade.

Critério da média: calculada somente quando os dois monitores possuem medidas válidas com até 3 minutos de idade e diferença máxima de 90 segundos entre seus horários. Caso contrário, a média principal é ocultada para não apresentar um valor enganoso. No gráfico, os registros são pareados pela proximidade temporal (até 45 segundos) e sem reutilizar leituras.

Atualização automática a cada 60 segundos. Os horários são exibidos no fuso local do navegador. Fonte de dados: API oficial do ThingSpeak. Sem dados simulados.
